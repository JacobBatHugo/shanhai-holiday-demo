# 山海课表 · 节假日与调休 Demo

公开交互预览：<https://jacobbathugo.github.io/shanhai-holiday-demo/>。所有课程、教师、教室和年历均为虚构演示数据；没有账号登录、真实 API 或持久化，刷新即重置。

## 当前版本 · 2026-10-30.2

- 设置、补课及“恢复上课？”确认框均居中；操作后的结果提示（如“10月1日已恢复上课”）位于可视区顶部约 20% 处。
- 保留紧凑的目标日期、来源、课程预览和操作结构。星期／指定日期、空／有课程、错误及覆盖确认切换时，补课表单外框保持稳定；短视口只滚动正文。
- 国庆采用新城楼与五星纹样；补课题签采用原创山茶枝 SVG，已移除旧紫藤图片。
- 删减重复说明；改善空预览空间与夜间花木对比；“继续编辑”保留表单内键盘焦点。
- 其他六节沿用统一纸笺、细线纹样。节日按钮可恢复当天或本次假期；恢复后不提供重新放假入口。
- 补课读取同周星期或学期内指定日期的原排课；空来源、无效日期、学期外及补课当天不可保存。替换已有课程需确认，支持撤销。
- 暂停自动调整保留规则，重新开启恢复；相关周临时展开周末。

## 本轮位置修正

用户澄清：确认框与操作结果提示是两类界面。只移动结果提示，确认框保持居中；所有结果提示共用定位。撤销与关闭均保留，关闭按钮触控区为 44×44px。沿用既有关闭／替换规则，不新增自动消失计时。其他已确认视觉保持不变。

## 验证

23 项测试、TypeScript、oxlint 和独立构建通过。Edge 实际页面检查覆盖 1440×1000、360×740、390×844、430×932、390×450，含日夜主题、日期日历、错误、保存、取消、重开、覆盖与撤销、焦点及开关保留。手机采用浏览器视口模拟，未测试实体手机软键盘。

## 本地开发

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
npm run preview
```

基础路径为 `/shanhai-holiday-demo/`。`docs/` 从同一份源码构建；`public/demo-version.json` 与构建产物一起更新提交。GitHub Pages 沿用 `main` 分支的 `/docs`，不新增工作流。
