# 山海课表 · 节假日与调休 Demo

独立交互预览，所有课程、教师、教室和年历均为演示数据。无账号登录、真实 API 或持久化；刷新会重置。

## 体验

- 顶部可切换国庆假期、调休补课、当天已有课、年历缺失等场景。
- 节日按钮只显示节日名称；点击可选仅恢复当天、恢复本次假期或取消，恢复后可重新放假。
- 补课可选同一教学周的星期或学期内日期，预览原排课；空来源不可保存，替换已有课程需确认。
- 关闭自动调整会保留规则；重新开启生效。相关周临时展开周末。
- 支持手机布局、日夜模式和键盘操作。

## 本地开发

需要 Node.js 24 与 npm。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
npm run preview
```

生产子路径为 `/shanhai-holiday-demo/`。`docs/` 是从同一份源码构建的静态文件；更新后重新构建并一起提交。

GitHub Pages 在仓库 Settings → Pages 中选择 Deploy from a branch，使用 `main` 分支的 `/docs` 目录发布。源码和静态产物均可公开查看。
