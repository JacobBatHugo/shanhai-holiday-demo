# 山海课表 · 节假日与调休 Demo

公开交互预览：<https://jacobbathugo.github.io/shanhai-holiday-demo/>。所有课程、教师、教室和年历均为虚构演示数据；没有账号登录、真实 API 或持久化，刷新即重置。

## 当前版本 · 2026-10-30.3

- 结果提示位于卷首山水下方、周序上方的独立反馈行。预留 56px，显示／消失不推动课表；不使用覆盖山水或周序的固定／吸顶定位。滚动后若反馈在视口外，只以 nearest 方式将反馈行滚入视口，不转移键盘焦点。
- 普通成功提示 5 秒自动消失；带撤销的提示 10 秒。鼠标悬停或键盘焦点在提示内时暂停，离开后给予完整阅读时间；触屏不会留下悬停状态。新操作重新计时，旧定时器清理，并以消息对象校验避免关闭新提示。弹窗打开期间提示卸载，计时停止。
- 关闭与撤销保留 44px 操作区。关闭时返回进入提示前的可用焦点；撤销补课后回到替换后的当天入口，撤销设置后回到课表设置。恢复确认及表单继续居中，补课外框、国庆图案和既有交互保持不变。
- 本版只修复反馈；花木仍是现有山茶枝。已检查本地项目／用户技能和插件缓存及工具目录，未发现 Imagen 技能或模型接口；只有 ImageGen，替代工具仍待确认，未生成或上传新图。
- 31 项测试，覆盖原 23 项与自动关闭、重复相同消息、旧计时器、悬停／触屏／焦点、撤销与卸载清理。实际 Edge 视口覆盖 1440×1000、360×740、390×844、430×932、390×450，普通提示在真实经过约 5.6 秒后消失；焦点保持时持续可用。

保留已确认的紧凑补课结构和稳定尺寸、居中确认、城楼五星纹样，以及暂停保留规则、空来源阻断、覆盖确认、撤销与日期校验。仅虚构示例；手机测试使用浏览器视口模拟，未测试实体手机软键盘。

## 本地开发

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
npm run preview
```

基础路径为 `/shanhai-holiday-demo/`。`docs/` 从同一份源码构建；`public/demo-version.json` 与构建产物一起更新提交。GitHub Pages 沿用 `main` 分支的 `/docs`，不新增工作流。
